Your webhook is on the default path /webhook

Automated scanners probe /webhook constantly, so your endpoint gets found without anyone looking for it. They still cannot trade — every signal needs the bot's API key — but each probe is logged and pushes a notification, which buries the alerts that matter.

Generate an unguessable one with pwgen -n 14 1 (or openssl rand -hex 8), set it as WEBHOOK_PATH in .env, restart, then update the URL in your TradingView alerts to match.
